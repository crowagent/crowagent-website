<div class="gl-tldr">
<h2>TL;DR</h2>
<ul>
<li><span><strong>What it is:</strong> the standard UK structure for scoring social value in bids.</span></li>
<li><span><strong>How it works:</strong> themes, then outcomes, then quantifiable measures.</span></li>
<li><span><strong>How you score:</strong> National TOMs 2023-24 proxy values turn measures into pounds.</span></li>
</ul>
</div>

<p class="gl-lead">The <strong>TOMs framework</strong>, <em>Themes, Outcomes, Measures</em>, is the most widely used structure for social value in UK public procurement.</p>
<p>It splits social value into three layers. <strong>Themes</strong> are high-level policy goals. <strong>Outcomes</strong> are the specific results sought. <strong>Measures</strong> are quantifiable deliverables.</p>
<p>Each measure is then turned into pounds of social value using proxy values from the National TOMs.</p>

<h2>Structure</h2>
<div class="gl-fact">
<ul>
<li><strong>Theme</strong>: policy area aligned to <a href="/glossary/ppn-002">PPN 002</a> missions (e.g. tackling economic inequality).</li>
<li><strong>Outcome</strong>: specific social change sought (e.g. more local employment).</li>
<li><strong>Measure</strong>: quantifiable deliverable scored using National TOMs proxy values (e.g. number of apprenticeships created, local spend, training hours).</li>
</ul>
</div>

<h2>Key facts</h2>
<ul>
<li><strong>Proxy values:</strong> <strong>National TOMs 2023-24</strong> is the canonical reference.</li>
<li><strong>Alignment:</strong> 5 PPN 002 missions map to TOMs themes.</li>
<li><strong>Evidence:</strong> each measure requires documented evidence (contracts, pay records, delivery reports) retained for audit.</li>
<li><strong>Scoring:</strong> measure quantity &times; National TOMs proxy &rarr; monetary social value &rarr; contributes to the minimum 10% weighting.</li>
<li><strong>Buyer discretion:</strong> buyers can choose which TOMs measures to score (they cannot reduce the 10% weighting, only add to it).</li>
</ul>
